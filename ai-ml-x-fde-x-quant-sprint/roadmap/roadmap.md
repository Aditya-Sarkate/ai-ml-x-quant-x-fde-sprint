# Sprint Roadmap

This roadmap is flexible and can expand as new technologies and research areas become relevant.

## Phase 1: Engineering Foundation
- Python, data structures, OOP, clean code
- Git, APIs, SQL, PostgreSQL, FastAPI, testing

## Phase 2: ML + Mathematics
- Probability, statistics, linear algebra, optimization
- Classical ML, model evaluation, feature engineering

## Phase 3: Quantitative Research
- Time series, factor models, statistical testing
- Portfolio construction, backtesting, risk management
- Walk-forward validation, quantitative ML

## Phase 4: Deep Learning
- PyTorch, neural networks, backpropagation
- Transformers, representation learning, research workflows

## Phase 5: LLM Engineering
- LLM fundamentals, embeddings, vector databases
- RAG, reranking, evaluation, LLM security

## Phase 6: AI Agents
- Tool calling, agent architecture, state management
- Planning, multi-step workflows, reliability, evaluation

## Phase 7: Production AI
- Authentication, databases, Redis, async Python
- Docker, observability, cloud deployment, system design

## Phase 8: Portfolio + Job Search
- GitHub, portfolio, technical writing, resume
- Networking, applications, interview preparation

## Potential additions
Cybersecurity, cloud infrastructure, distributed systems, DevOps,
data engineering, computer networks, open-source contribution, and research papers.
